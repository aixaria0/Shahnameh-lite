# شاهنامه — خوانش، روایت، خرد

نسخه‌ای سبک، فارسی و منظم برای ورود به جهان شاهنامهٔ فردوسی؛ با نقشهٔ روایت‌ها، چهره‌های اصلی، درون‌مایه‌ها، واژه‌نامه، گزیدهٔ آغاز کتاب و جست‌وجوی محلی.

## ویژگی‌ها

- رابط کاملاً فارسی و راست‌به‌چپ
- سه پهنهٔ روایی: اساطیری، پهلوانی و تاریخی
- کارت‌های روایی و پروندهٔ شخصیت‌ها
- واژه‌نامهٔ فشرده برای مفاهیم کلیدی
- جست‌وجوی سریع بدون سرویس بیرونی
- بیت‌نما با خوانش مرورگر و کپی سریع
- «حکیم توس» با پاسخ محلی برای پرسش‌های مربوط به محتوای همین نسخه
- پنج لحن خوانش محلی: حکیمانه، حماسی، نقالی، شاعرانه و آرام
- بخش اختیاری Gemini برای پرسش‌های بازتر و صدای استودیویی
- بدون حساب کاربری، پایگاه داده یا کلید ازپیش‌قرارگرفته‌شده
- خروجی کاملاً استاتیک و مناسب GitHub Pages

## اجرا

```bash
npm install
npm run dev
```

برای بررسی کامل:

```bash
npm run verify
```

## معماری مستقل و اتصال اختیاری

خواندن، جست‌وجو، واژه‌نامه، پاسخ‌های محلی و خوانش صوتی مرورگر بدون کلید و بدون سرویس بیرونی کار می‌کنند. اگر کاربر پاسخ گسترده‌تر یا صدای استودیویی بخواهد، می‌تواند کلید Gemini خودش را از داخل تنظیمات وارد کند. کلید فقط در `sessionStorage` همان تب نگه داشته می‌شود و با پایان نشست از بین می‌رود.

برای صدای استودیویی از `gemini-3.8-flash-tts` با صدای `Charon` استفاده می‌شود؛ اگر این اتصال در دسترس نباشد، خوانش محلی خودکار جایگزین می‌شود.

## انتشار

```bash
npm run publish:pages
```

خروجی به‌صورت پیش‌فرض در مسیر `/shahnameh-lite/` منتشر می‌شود. مسیر را می‌توان با متغیر `PAGES_SUBDIR` تغییر داد.

## مرز محتوا

این پروژه یک راهنمای ورود و مرور است، نه نسخهٔ انتقادی شاهنامه. برای نقل دقیق ابیات، شماره‌گذاری بخش‌ها و اختلاف نسخه‌ها باید به تصحیح معتبر چاپی مراجعه کرد.
